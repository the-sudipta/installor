# Installor v0.2.0 — Guided cross-device libraries

Installor v0.2.0 turns Google Sheets synchronization into a complete end-user workflow and makes large software inventories practical to review. A named device can scan and approve applications in bulk, upload its existing library, and other named devices can receive the same catalog with precise location information.

## Highlights

- **Guided Google setup:** the desktop app generates a private secret, displays the complete version-matched Apps Script, copies it in one click, verifies the deployment, and offers a full-library push.
- **Real cross-device workflow:** synchronize catalog records, device-specific installation records, and deletion tombstones between connected devices.
- **Bulk detected-software review:** select visible results, clear selection, add selected applications, or add all remaining results.
- **Bulk safe removal:** remove selected catalog records with an explicit boundary—Installor does not uninstall applications or delete files.
- **Understandable synchronization:** see what was uploaded, downloaded, removed, and left pending, plus the last successful sync time.
- **Help where decisions happen:** contextual information controls explain pages, metrics, selections, URLs, secrets, synchronization, device names, and installer actions.
- **Named device categories:** saved names such as **Office Desktop** and **Research Laptop** become catalog filters, with a details dialog for versions, paths, and verification times.

## Named devices → Sheet → named devices

1. On a device named **Office Desktop**, scan, select useful applications, and add them to the catalog.
2. Open **Settings → Set up Google synchronization** and complete the five guided steps.
3. Choose **Push entire local library** once, then use **Sync with Sheet** for later changes.
4. On **Research Laptop**, configure the same Apps Script deployment and shared secret, save that distinct device name, and synchronize.

The catalog appears with device categories created from names such as **Office Desktop** and **Research Laptop**. Sync exchanges metadata only; it never performs a scan, download, installation, uninstallation, or file deletion.

## Reliability improvements

- Full-library pushes backfill records created before synchronization was configured.
- Duplicate queued upserts are collapsed to the current snapshot.
- Pending local removals take precedence over remote list data, preventing deleted records from reappearing.
- The Apps Script bridge stores deletion tombstones so removals propagate across computers.
- Automated coverage grows to 20 Rust tests and 7 interface tests.

## Downloads

Release assets include Windows installers and a standalone executable, plus native packages generated by the tagged macOS and Linux build jobs. Compare downloads against `SHA256SUMS.txt`. Packages are not code-signed or notarized; review the documented platform status before evaluation.

## Upgrade notes

Existing v0.1.x local databases are retained. To use cross-device removals, redeploy the v0.2.0 script shown inside Installor; older bridge deployments do not understand deletion tombstones. After connecting, choose **Push entire local library** once to backfill all current records.
