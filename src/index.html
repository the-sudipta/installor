Clear privacy boundaries

  • Public import: anonymous and read-only.
  • Local catalog: stored in SQLite on this device.
  • Bridge secret: generated locally and stored in the OS credential vault.
  • Sync: exchanges catalog metadata and device installation records.
  • Remove: never uninstalls applications or deletes files.
  • Install: begins only after explicit selection and confirmation.
